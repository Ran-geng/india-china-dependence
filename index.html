01 · Trade Overview

中印贸易概况

中国是印度最大贸易伙伴之一。印度对华长期呈现巨额贸易逆差，且逐年扩大——印度向中国出口以矿产、金属等初级原材料为主，而自中国进口的多为电子、机械等高附加值成品。

    05 · Data Sources & Freshness

    数据来源与更新

    本站数据整合三类权威公开来源。各源更新频率、覆盖范围与接入方式如下；受官方发布节奏（月度/财年）与免费 API 限制，推荐以每月一次的方式定期更新（而非实时抓取）。页面所有图表与明细均标注来源编号与口径。

    如何保持数据新鲜（推荐：每月定期更新）

    • 定期更新（推荐，每月 1 次）：海关与商务部均为月度/财年发布，无实时数据流；本站采用 GitHub Actions 定时工作流（每月 1 日 + 可手动触发）运行 refresh_monthly.py，刷新 LAST_UPDATED 并补录最新官方值，避免脆弱的实时爬取。
    • UN Comtrade（受限，备用）：免费档仅返回「全球」口径，印度-中国双边明细需付费订阅；当前 key 有效但取不到双边，故 Comtrade 暂不作为主更新源，update_data.py 保留备用。
    • 中国海关总署（人工）：官网 customs.gov.cn 每月中旬发布上月快讯，无开放 API，需人工录入或解析 PDF 后更新 data.js。
    • 印度商务部 DGCIS（人工）：commerce.gov.in / 驻华使馆发布月度贸易公告与财年汇总，部分经 Lok Sabha 答复、PIB，无开放 API，需人工更新。

    本网站所有数据与结论均基于以下真实公开来源整理，力求准确、可溯源。文中角标数字对应下列来源编号。不同来源的统计口径（财年/自然年、HS 编码、数据发布机构）可能存在差异，引用时已尽量标注口径。本站仅供研究参考，不构成任何投资或政策建议。

    口径提示：印度官方多采用财年（4 月–次年 3 月）口径，中国海关采用自然年口径，两者数据存在正常差异。例如中国海关口径 2025 年中印双边贸易额约 1556.2 亿美元、印度逆差约 1161.2 亿美元19；而印度财年口径 2024-25 双边约 1277 亿美元、逆差约 992 亿美元1。
